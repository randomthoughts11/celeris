2026-07-31 — Flux audit fixes (P0–P2)
------------------------------------
Security / integrity
- Signed OAuth state (HMAC) for Drive, Google Ads, and Meta; Drive connect requires
  auth + company ACL; callback verifies user + company.
- Deck stack/label/card/comment mutations join deck_boards.company_id (no cross-company IDOR).
- New users default to designer (pending); session no longer invents manager.
- Only god_mode can assign god_mode. Telecaller lead/call writes enforce owner_id.
- Meta sync sets absolute spend (no longer accumulates). Middleware fails closed on DB errors.

UX / product
- Mobile hamburger for Chat / Vault / Team / Settings / Admin.
- Overview financials gated by VIEW_FINANCIALS; denied tabs redirect to role home.
- Vault create/share require company access; shares limited to company members.
- Notifications on lead create, task assign, and card comments.
- Board: My = assignee or creator; Created by me; managers default to Team.
- Publishing Hub copy honest (no in-app approvals); orphaned scheduler UI removed.
- Smart alerts (renamed) with deep links; Google Ads MCC header + LAST_30_DAYS;
  Meta token refresh near expiry; keyboard DnD; breadcrumb uses DB company name;
  role badge uses getHighestRole; chat polls faster when tab visible.
- RingCentral adapter returns honest errors (webhook/manual log remain the path).

Optional env: GOOGLE_ADS_LOGIN_CUSTOMER_ID (or GOOGLE_ADS_MCC_ID) for MCC client sync.

2026-07-28 — Password vault
---------------------------
- New Vault page (/vault) in global nav for storing agency and brand credentials.
- Passwords encrypted at rest (AES-256-GCM, keyed by AUTH_SECRET) and never sent
  to the browser in lists; decrypted server-side only on reveal/copy.
- Per-credential sharing: creator (or admin) picks which teammates can access.
  Admins and god_mode see everything. Telecallers see only what is shared.
- Every password reveal is audit-logged and appears in the activity feed.
- Entries support category, company/brand tag, username, URL, notes, and a
  strong-password generator. Search and category filters included.
- DB: migration 009 (vault_credentials, vault_credential_access) — applied.
